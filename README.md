# SDSS-DR18-Pipeline
Pipeline automatizado que rescata datos del SDSS, grafica Índice de Color (g-r) vs Redshift (z), y a partir de esto clasifica y analiza cómo se distribuyen las Galaxias Locales frente a los Quásares primordiales. Primer proyecto elaborado como entrega para el curso de Minería de Datos en Astronomía (UdeA). Ciencia de Datos Abierta y Reproducible.
